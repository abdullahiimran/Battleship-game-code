# Battleship-game-code
done by: Muhammad Abdullah (26L-0833), Hassaan Suhail (26L-0800), and Hassan Bhatti (26L-0835)
## Basic Overview
Battleship Strategy i a GUI based C++ game which is played by two players. Each player has his separate grid in which he can place a boat. After all ships have been placed, the players take turns in destroying the opponents ships. The player who destroys the ships of the opponent first wins. 
## Main Features in the Game
* Two-player Gmeplay
* An Instructions menu
* Two boards using two 2D arrays
* Input validation
* Turn based attack
* Hit and Miss detection
* Winner detedtion
* Closing menu
* Restart option
## Concepts used
1. 2D arrays used to make boards
2. Functions used to make the code easier to understand
3. Fundamental Concepts of Raylib and C++
4. /a used to make sound
## Prerequisites
the user should have a windows 10/11 (64 bits) in which Visual studio and raylib is installed
## Installation and Setup
copy the main code, download the pictures and add them in the VS 2026 application. Go to Nuget Packet Manager in the tools ribbon. from there go to Manage Nuget Packages for Solution... and from there go to Browse and search Raylib there and install it while checking the project checkbox.
